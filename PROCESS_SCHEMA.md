## Связь между этапами и документами / Phase-Document Mapping

| Этап / Phase | Ключевые документы / Key Documents | Ответственный / Responsible |
|--------------|-------------------------------------|----------------------------|
| 01_Initiation | Устав проекта, Первичные требования | Спонсор, PM |
| 02_Planning | План проекта, ТЗ, Реестр рисков | PM, Команда |
| 03_Execution | Журнал работ, Протоколы, Результаты НИОКР | Команда |
| 04_Monitoring | Отчеты о статусе, Метрики, Аудиты | PM, Контроль качества |
| 05_Closure | Итоговый отчет, Акт приемки, Уроки | PM, Спонсор |
